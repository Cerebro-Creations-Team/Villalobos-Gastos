# Comprobante de gastos · Agencia Aduanal Villalobos

Herramienta interna para armar el comprobante de gastos de una operación a partir de los CFDI (XML) y PDF, y descargarlo en Excel con el formato del libro de cuentas.

- Sitio: https://gastos.villalobosaduanal.com (GitHub Pages, dominio en `CNAME`).
- Todo corre en el navegador: los XML y PDF no se suben a ningún servidor.
- Sin paso de compilación: HTML, CSS y JS estáticos. ExcelJS y pdf.js se cargan desde cdnjs.
- No se indexa en buscadores (`robots.txt` y meta `noindex`).
